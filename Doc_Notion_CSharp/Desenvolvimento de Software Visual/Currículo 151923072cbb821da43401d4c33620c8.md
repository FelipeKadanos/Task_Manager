## Projetos de TCC

---

**2023 - GOCHEFF - Aplicativo de Eventos Gastronômicos Personalizados**

Eventos gastronômicos são essenciais no mercado pós-pandemia. Embora aplicativos de alimentos estejam em alta, a falta de opções especializadas para eventos persiste. Um novo aplicativo nativo para Android busca preencher essa lacuna, facilitando a contratação e prestação de serviços personalizados em eventos gastronômicos.

---

**2021 - CHOCOFY**

O setor alimentício brasileiro é vital e em crescimento, com distribuidoras buscando novas estratégias para se destacar. A proposta Chocofy visa criar um canal de vendas que ofereça uma experiência de compra conveniente para padarias, confeitarias e mercados, enquanto permite que as distribuidoras se diferenciem no mercado. Com uma aplicação web para distribuidoras e um aplicativo móvel para clientes, o objetivo é proporcionar uma vitrine digital de produtos, promover ofertas e melhorar a logística de compras sem sair do estabelecimento.

---

**2020 - BAGGINS**

Promover integração turística enfrenta desafios, como falta de recursos e coragem para aventuras. O projeto Baggins desenvolve um sistema multi-plataformas, web e mobile, focado nas experiências e habilidades dos usuários como moeda de troca por oportunidades de voluntariado ou trabalho colaborativo em destinos desejados. Além disso, oferece um sistema de recomendação de destinos alinhados aos interesses dos usuários, com o objetivo de se tornar uma plataforma internacional.

---

**2020 - BAGGINS**

O projeto Workalt consiste em um aplicativo para Android e iOS que conecta personal trainers certificados a pessoas interessadas em praticar exercícios físicos com orientação profissional. Utilizando JavaScript em todas as frentes, o backend é em Node.js com Adonis.js, a plataforma web em React.js e o aplicativo em React Native. Os personal trainers pagam uma taxa única para divulgar suas aulas, enquanto os alunos podem encontrar aulas gratuitamente e iniciar conversas diretamente na plataforma para combinar detalhes.

---

**2020 - TEST ANALYZER**

O Test Analyzer é uma plataforma web desenvolvida para facilitar a correção de questões discursivas em sistemas de avaliação online. Utilizando processamento de linguagem natural (PLN) e bibliotecas especializadas, a plataforma automatiza a correção com base em dicionários e análise de similaridade. Além disso, oferece a criação de provas com questões objetivas e discursivas, mantendo o sistema de correção automatizado.

---

**2019 - DAX BIER**

O projeto DaxBier propõe unir bolsa de valores e cerveja artesanal em eventos, oferecendo soluções para carteira, créditos, retiradas de produtos e compra/venda de produtos. Utiliza Ruby on Rails para a API, Angular para o frontend web e Flutter para o aplicativo mobile. O sistema visa otimizar processos para cervejarias, organizadores de eventos e participantes, oferecendo uma experiência conveniente e divertida, além de facilitar a gestão de créditos e comissões.
